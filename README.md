# 漸好 · The World Is Slowly Getting Better

一個極簡主義的雙語（繁體中文／英文）網站，收錄十二則來自過去五年（2021–2025）、經聯合國、世界衛生組織、國際能源總署等機構驗證的紀錄，說明世界正在緩慢但真實地變好。

A minimalist, bilingual (Traditional Chinese / English) website presenting twelve verified records from the past five years (2021–2025) — sourced from the WHO, UN, IEA, and other institutions — showing that the world is slowly but genuinely improving.

## Files

- `index.html` — page structure and content
- `styles.css` — minimalist serif visual system
- `script.js` — subtle scroll-reveal for each record

## Design

- Serif typography throughout: Noto Serif TC for Chinese, EB Garamond for English/Latin text.
- Chinese and English are presented side by side for every heading, paragraph, and source citation — no language toggle.
- Warm paper background, a single muted accent color, hairline dividers, no imagery or heavy UI chrome.
- Every record links to its primary source.

## Open Locally

Open `index.html` in a browser to view the site.
